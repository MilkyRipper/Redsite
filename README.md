# Redsite – Car Wash Website

A modern car wash website designed to showcase car wash services and provide visitors with an attractive browsing experience.

## Features
- Modern and clean design.
- Responsive layout.
- Car wash service presentation.
- User-friendly interface.

## Technologies Used
- HTML5
- Tailwind CSS

## Project Purpose
This project was created to improve my frontend development skills and gain practical experience building responsive websites with Tailwind CSS.
